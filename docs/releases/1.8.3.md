# Custom Codex UI 1.8.3

This patch fixes conversations opening at the beginning instead of the latest
messages, including when returning to a retained conversation tab.

- Restore the tail of the native conversation scroller after asynchronous
  history loading and initial layout changes. Prefer the app's own latest-message
  action when available.
- Limit automatic positioning to initial conversation activation. Manual wheel,
  touch, pointer or paging input stops it immediately.
- Preserve reading positions when switching window focus, reapplying a theme or
  updating an unchanged active-page marker.
- Leave sidebar, settings and document-preview scroll positions alone. Release
  pending timers and observers after restoration or theme removal; ongoing token
  streaming does not cause whole-document scroll scans.
- Include the fix in all nine themes. Supported Codex Store versions remain
  26.1021.2667.0 and 26.1021.3705.0.

Extract the Windows x64 portable ZIP into a writable local folder and run
Setup.ps1. Profiles, conversation history and local settings are excluded from
the archive. Keep existing private data directories when updating.

The theme uses an unauthenticated debugger on a random loopback port. Use only
on a trusted computer and do not forward that port.
