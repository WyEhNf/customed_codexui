## Fix

Recover the native viewport after an interrupted CDP recording. A stale
screencast or emulated device/DPI state could make the app alternate between
the full interface and a magnified upper-left region.

Theme startup now stops stale capture, clears device metrics emulation and
releases emulated focus once per target. Idle checks do not repeat the reset.
Native window bounds, browser zoom, drafts and later deliberate recordings are
preserved. Diagnostics remain read-only.

This release also includes the v1.8.0 session hardening: random loopback CDP
ports, verified graceful recovery, separate agent data, protected data
directories, validation-stage cleanup, and actual client compatibility checks.
CDP is still unauthenticated; random ports are not an authentication boundary.

## Installation

Download `CodexUI-Integrated-1.8.1-Windows-x64.zip`, verify it with
`SHA256SUMS.txt`, extract to a permanent writable local folder outside OneDrive,
Program Files and Windows, then run `Setup.ps1`. The official Codex desktop app
must be installed; the tested Appx package version is **26.1021.2667.0**.

For an existing installation, finish active work and use its restore entry to
exit the old themed client before installing. All themes share their own
`profile/` and `codex-home/`; existing `~/.codex` credentials and history are not
copied. Sign-in or tool setup may be required when first using the isolated
agent home. `RELEASE.json` records the source commit and complete package hash.
